# RestaurantOS 🍽️
A responsive Restaurant Inventory & Employee Attendance Management System built using HTML, CSS and JavaScript.

## Features

- Multi-location inventory management
- Employee attendance tracking
- Add / Edit / Delete records
- Search and filter functionality
- Dashboard with live metrics
- Responsive dark UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Modules

1. Inventory Management
2. Attendance Management

## Future Improvements

- Local Storage
- Login Authentication
- CSV Export
- Sales Analytics
